# Contributing to Caesar Cipher Suite

Thank you for your interest in contributing to the Caesar Cipher project!

## 🚀 How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/caesar-cipher-java.git
   ```
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/my-feature
   ```
4. **Make your changes** and add unit tests in `src/com/cipher/CipherDemoTest.java`.
5. **Verify that tests pass**:
   ```bash
   javac -d bin src/com/cipher/*.java
   java -cp bin com.cipher.CipherDemoTest
   ```
6. **Commit with a descriptive message**:
   ```bash
   git commit -m "feat: implement Vigenere cipher extension"
   ```
7. **Push to your fork** and open a **Pull Request**!
